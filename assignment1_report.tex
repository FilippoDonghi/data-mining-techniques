\section{Task 1A: Exploratory Data Analysis}
The raw dataset contains 156 responses and 16 columns. After standardizing the column names, the timestamp was parsed as a datetime value and the remaining variables were treated according to their type. The dataset mixes categorical survey answers, free text, and several numeric responses that were not always entered in a structured form.

The programme field was highly heterogeneous, so spelling variants and aliases were grouped into broader categories. After grouping, the distribution is concentrated in a small number of study tracks: AI (50), Computer Science (30), Finance / Econometrics (21), Business Analytics (19), Bioinformatics (16), Other (12), and Computational Science (8).

\section{Task 1B: Data Cleaning and Imputation}
The cleaning script standardized the raw survey answers before imputation. Text fields were stripped of extra whitespace, binary answers were normalized to yes/no, the programme field was mapped to a smaller set of semantic categories, and the timestamp was parsed into a datetime column. Structured numeric fields were parsed separately for birth year, room estimate, stress, sports hours, random number, and bedtime.

We then applied domain rules to remove clearly invalid values. Stress values outside 0--100 were set to missing, negative sport values were removed, bedtime values were constrained to the 0--24 range, and negative room estimates were discarded. In addition, room estimate and sports hours were passed through an IQR-based filter to remove extreme outliers. After these steps, the cleaned dataset retained the original row count but had fewer unreliable field values.

The imputation stage compared two standard approaches. The first uses median imputation for numeric variables and most-frequent imputation for categorical and free-text variables. This is a conservative baseline and is robust to skewed distributions and outliers~\cite{little_rubin_2002}. The second uses KNN imputation with five neighbors and distance weighting for numeric variables, while keeping the same categorical/text fallback. KNN imputation can preserve local structure in the data better than a single global statistic~\cite{troyanskaya_2001}.

\section{Task 2A: Application of Classification Algorithms}
For the classification task we use the cleaned basic dataset \texttt{task1b/clean\_imputed\_simple.csv} with 156 instances. The class to predict is \texttt{ir\_course}, mapped to a binary target (yes=1, no=0). The class distribution is mildly imbalanced (58 yes, 98 no), so we evaluate performance primarily with the F1-score, which balances precision and recall and is more informative than plain accuracy under imbalance~\cite{rijsbergen_1979}.

\subsection*{Reproducible Pipeline}
All experiments were run with a fixed random seed (42) in script \texttt{task2a/task\_2a.py}. We used a stratified train/test split (80\%/20\%), yielding 124 training and 32 test instances.

The preprocessing and modeling pipeline was implemented with scikit-learn~\cite{pedregosa_2011}. We derived two numeric timestamp features (hour and weekday), removed free-text fields (\texttt{good\_day\_1}, \texttt{good\_day\_2}), one-hot encoded categorical attributes, and applied median/most-frequent imputation where needed. Numeric features were standardized to support distance-based learning.

We compare two classification algorithms discussed in class:
\begin{itemize}
\item Decision Tree classifier~\cite{breiman_1984}
\item k-Nearest Neighbors (k-NN)~\cite{cover_1967}
\end{itemize}

\subsection*{Hyperparameter Optimization}
Hyperparameters were tuned with grid search and 5-fold stratified cross-validation on the training set, optimizing F1-score.

\section{Task 2B: Winning Classification Algorithms}
To study a high-performing real-world classification approach, we analyzed the winner of the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) 2015 classification track~\cite{russakovsky_2015}. Although Kaggle and KDD Cup are common platforms, ILSVRC is also a landmark machine learning competition and a strong example of how winning approaches differ from standard baselines.

\subsection*{Competition Description}
ILSVRC 2015 is a large-scale image classification competition with 1{,}000 classes and more than one million training images from the ImageNet dataset~\cite{russakovsky_2015}. The core task is multi-class classification: assign each image to the correct object class. The primary evaluation measure is top-5 classification error, i.e., an image is counted as correctly classified if the true class appears in the model's five highest-confidence predictions.

\subsection*{Winner and Technique}
The winner of ILSVRC 2015 classification was the Microsoft Research team, using the Residual Network (ResNet) architecture~\cite{he_2016}. Their model family (up to 152 layers) achieved state-of-the-art accuracy at the time and significantly improved over earlier deep convolutional networks.

\subsection*{Main Idea of the Winning Approach}
The key idea is residual learning. Instead of learning a direct mapping $H(x)$, each residual block learns a residual function $F(x)=H(x)-x$ and outputs $F(x)+x$ through shortcut (skip) connections. This design improves gradient flow during training and makes very deep networks trainable without severe degradation problems. In practice, this allowed much deeper models than standard plain CNN stacks while maintaining optimization stability~\cite{he_2016}.

\subsection*{Why It Stood Out}
Compared with non-winning or standard architectures of that period, the winning approach stood out for three reasons:
\begin{itemize}
\item It enabled substantially deeper networks with better optimization behavior due to skip connections.
\item It improved generalization and reduced classification error at large scale.
\item It provided an architectural principle (residual blocks) that transferred well to many later tasks and became a default baseline in computer vision.
\end{itemize}

In short, the winning method was not only a parameter tuning improvement over standard CNNs; it introduced an architectural innovation that changed how classification models are designed and trained.
